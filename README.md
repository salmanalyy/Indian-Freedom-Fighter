 # Indian Freedom Fighters

A simple and informative website built using HTML and CSS to honor and showcase the brave heroes who fought for India's independence.

# 🧾 Project Overview

This project presents information about key Indian freedom fighters, their contributions, and their role in India’s struggle for independence.
It is designed using HTML for structure and CSS for styling, focusing on clean design, readability, and responsiveness.

# 🧰 Technologies Used

▪️HTML5 – For creating the structure and content of the web pages.

▪️CSS3 – For adding styles, layout, and responsive design.

# 🖥️ Features

💬 Profiles of famous Indian freedom fighters (e.g., Mahatma Gandhi, Bhagat Singh, Rani Lakshmi Bai, etc.)

🖼️ Images and short biographies

📱 Responsive design that works on different screen sizes

🎨 Simple and elegant UI design
